      Hébergement OVH

      Les informations FTP se trouvent dans l'espace client OVH, rubrique Hébergements, onglet FTP-SSH. Le mot de passe est demandé à chaque publication et n'est jamais enregistré.

        Guide OVH

        Les étapes à faire une seule fois, puis la routine de mise à jour.

        1. Préparer l'hébergement
        1. Commandez un hébergement web OVH (l'offre Perso suffit pour ce site) et le nom de domaine.
        2. Dans l'espace client : Web Cloud, puis Hébergements, puis votre hébergement, onglet Multisite. Vérifiez que le domaine pointe vers le dossier www.
        3. Dans le même onglet Multisite, activez le certificat SSL gratuit (Let's Encrypt). Il devient actif en quelques heures.
        2. Trouver les accès FTP
        1. Onglet FTP-SSH de votre hébergement.
        2. Le serveur FTP ressemble à ftp.cluster0XX.hosting.ovh.net : recopiez-le dans « Serveur FTP ».
        3. L'identifiant FTP principal est affiché sur la même page.
        4. Mot de passe oublié : bouton « Modifier le mot de passe » dans la liste des utilisateurs FTP.
        3. Première publication
        1. Remplissez toutes les valeurs, puis cliquez sur Enregistrer.
        2. Vérifiez l'aperçu, notamment la page Contact.
        3. Si OVH a mis une page « Site en construction » dans www, supprimez le fichier index.html d'OVH avec le gestionnaire FTP de l'espace client, ou cochez « Tout renvoyer ».
        4. Cliquez sur Publier sur OVH et saisissez le mot de passe FTP. Le premier envoi transfère tout le site (une centaine de fichiers).
        5. Ouvrez le site en ligne et testez une demande de réservation.
        6. Si le site ne s'ouvre pas et que le navigateur signale un certificat invalide, le SSL n'est pas encore actif : décochez « Forcer le HTTPS », enregistrez, publiez, puis recochez une fois le cadenas disponible.
        4. Mettre à jour les prix ou les dates
        1. Lancez l'outil (npm run admin ou double-clic sur « to-spiti-mas-administration »).
        2. Modifiez les valeurs, cliquez sur Enregistrer, vérifiez l'aperçu.
        3. Cliquez sur Publier sur OVH : seuls les fichiers modifiés partent, en quelques secondes.
        En cas de problème
        • Mot de passe refusé : réinitialisez-le dans l'onglet FTP-SSH, attendez quelques minutes, réessayez.
        • Connexion chiffrée refusée : décochez « Connexion chiffrée » dans Hébergement OVH, puis réessayez.
        • Envoi interrompu : relancez Publier, l'envoi reprend où il s'est arrêté.
        • Site différent de l'aperçu : cochez « Tout renvoyer » à la publication.
        • Solution de secours sans cet outil : générez le site, puis envoyez le contenu du dossier dist dans www avec FileZilla. Le fichier caché .htaccess doit être envoyé aussi.

        Publier sur OVH

        Le site est régénéré, puis seuls les fichiers modifiés sont envoyés.
